# CMS HOA Android Releases

Download the CMS HOA Android app from this repository’s [Releases](../../releases).

## Installation

1. Open the latest release on your Android device.
2. Download the attached `.apk` file.
3. Open the downloaded file.
4. If prompted, allow your browser to install unknown apps.
5. Tap **Install**.

No GitHub account is required.

## Updating

Download and install the latest APK over your existing app. You do not need to uninstall the previous version.

## About this repository

This repository hosts Android installation files only. The application’s source code is maintained separately.

Direct APK downloads are available while the app awaits Google Play approval.
